# Integration Plan

## Email

Primary provider: Gmail

Core permissions:
- Read messages and labels
- Draft messages
- Send approved messages
- Schedule sends where provider supports it

## Calendar

Primary provider: Google Calendar

Core permissions:
- Read events
- Create and update events
- Cancel approved events
- Email attendees with approved messages

## Work Boards

Primary provider: Notion

Core permissions:
- Read tasks/databases
- Create and update cards
- Link meetings and emails to tasks

## Relationship Graph

Providers: Gmail contacts, Google Calendar attendees, LinkedIn, CRM, and Notion board context

Core permissions:
- Import contact graph
- Rank paths to target people
- Draft outreach and intro requests
- Avoid manual target entry for the default flow

## Collaboration Intake

Each collaborator should answer:
- What app do you want connected?
- What data should the assistant read?
- What actions can it draft?
- What actions can it execute after approval?
- What should it never do?
